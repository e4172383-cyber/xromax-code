# XroMax Code

ИИ-агент для кода под Windows 10/11 от XROMAX: работает с файлами и командами на вашем ПК, подключает любые API (OpenAI, Anthropic, OpenRouter, DeepSeek, Gemini, свои), подписку ChatGPT, бесплатные модели XroMax, UltraCode с субагентами, плагины, скиллы и MCP-коннекторы.

Это исходный код **клиентского приложения** — чтобы любой мог проверить, что оно делает на компьютере и куда отправляет данные. Серверная часть XROMAX сюда не входит.

## Что важно знать о безопасности
- Ключи API хранятся только на вашем ПК, зашифрованные средствами Windows (`safeStorage`), см. `main.js`.
- Опасные действия агента (удаление вне проекта, системные папки, реестр, force-push) требуют вашего подтверждения в режиме «Авто» — см. `core/tools.js` (`assessRisk`).
- Обновления проверяются по подписи Ed25519: публичный ключ — `signing/update-public.pem`, проверка — `core/update-sign.js`. Закрытый ключ в репозиторий не входит.
- Сеть: приложение обращается к выбранным вами поставщикам моделей и к `xromax-ai.defhosting.com` (вход, бесплатные модели, лимиты, копии чатов — копии можно выключить в «Конфиденциальности»).

## Сборка
```
npm install
npm start          # запуск из исходников
npm test           # тесты инструментов и агента
npm run dist       # установщик (без нашей подписи обновлений)
```
